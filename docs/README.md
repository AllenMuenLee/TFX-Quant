## 不可妥協的安全前提

- 交易商品固定為小台指（MXF）。UI 的小台／大台切換只改變行情監看，不改變委託商品。
- 最大淨持倉 2 口，不留倉，每日 04:55（Asia/Taipei）前完成收盤平倉。
- 反手必須先收到原部位「完全平倉」的確定成交回報，再建立反向 1 口。
- 部分成交、逾時、拒單、斷線、委託狀態不明、持倉不一致時一律進入安全暫停等待人工確認。
- **本軟體不取代券商端人工確認。** 任何異常情況下，操作人員仍須依券商規定向元大營業員或櫃台確認。
