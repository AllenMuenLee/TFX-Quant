# Feature 03 — Instrument and Contract Selection

> **API 文件唯一來源：實作前必須直接讀取專案根目錄 [`交易API元件及說明文件/`](../../交易API元件及說明文件/) 內的元大期貨交易 API 說明、Python 範例、元件與版本資訊。禁止使用 SPARK API 網站、舊 SPARK SDK、舊範例或既有 SPARK 程式碼反推 API；若與本 prompt 其他描述衝突，以該資料夾內文件為準。資料夾缺少、文件未明載或內容矛盾時，須停止相關實作並列為 blocker。市場價格、行情與 OHLCV 不屬於此交易 API 規格，一律使用 `yfinance`。**
> **不得臆測：API 名稱、參數、回傳值、事件、錯誤碼、登入方式、環境、平台、位元數與能力都必須有上述官方文件依據；文件未明載者須標成待確認並隔離於 adapter，不得自行補造。**

> 強制使用 Python 開發；商品主檔、驗證與切換流程須實作成可測試的 Python services。

## 任務

實作小台指與大台指的市場行情切換、契約月份自動解析與有效性驗證。此處的商品切換只影響元大行情訂閱與圖表；所有交易委託固定為小台指（MXF）。商品代碼、契約格式、到期日與可交易月份必須取自元大 API 或受控商品主檔，不得把可能變動的代碼規則散落在程式中。

## 必須實作

- 建立商品主檔服務，能表示小台／大台、契約代碼、月份、到期日、tick size、乘數、交易時段與是否可交易。
- UI 只允許選擇要監看的小台指或大台指行情；契約一律由受控商品主檔自動解析為最近可交易月份，畫面只顯示解析後的 `YYYY-MM`，不得提供手動契約輸入、下拉選單或手動模式設定。
- 策略執行中禁止切換市場行情；已安全暫停或停止時可切換。行情切換不得因線上持倉或活動委託而改變既有／未來委託的商品 identity。
- 切換流程停止舊元大行情註冊、驗證新 EASYWIN／官方行情代碼、註冊新商品、恢復本機歷史並清空新行情 identity 的形成中 K 棒與訊號狀態；成功後仍需使用者重新啟動策略。
- 到期、停止交易、主檔缺漏、價格跳動單位不符時禁止建倉並顯示原因。
- 所有委託都攜帶小台指（MXF）與完整契約識別；OrderManager 必須拒絕任何非 MXF 委託，不允許依 UI 當下行情選項改寫既有或新委託。

## 除錯日誌需求

- 記錄商品主檔載入／更新、候選契約解析、近月選擇、tick size／到期／交易狀態驗證，並含 master-data version、來源、商品、契約及每項規則結果。
- 每次切換須使用 workflow ID 串起暫停、舊訂閱取消、帳戶查詢、新訂閱、K 棒／訊號重置與完成結果，各步驟記錄耗時及失敗原因。
- 被拒絕的切換或啟動須記錄行情商品、解析契約及策略狀態；任何非 MXF 送單嘗試須記錄並在持久化 intent 前拒絕。

## 驗收

測試小台／大台行情切換、跨年月份、到期日、主檔更新及無有效契約。證明 UI 沒有手動契約控制、契約只顯示 `YYYY-MM`、持倉／委託不會被行情切換改寫，且所有非 MXF 委託在 OrderManager 邊界被拒絕。
