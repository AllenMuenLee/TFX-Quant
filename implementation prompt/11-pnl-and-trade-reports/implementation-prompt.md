# Feature 11 — Realized P&L and Trade Reports

> **平台硬性限制：整個系統只能使用 x32；不得使用 x86 或 x64。原因是行情 API 僅提供 x32 版本。所有開發、相依套件、執行環境、測試、建置與部署均須遵守此限制。**

> 強制使用 Python 開發；損益計算須使用 Python `decimal.Decimal` 或整數最小貨幣單位，禁止 `float`。

## 任務

依元大實際成交回報建立不可變成交台帳，計算並顯示每日及每月「實際成交」損益與交易明細。不得以委託、訊號或未成交價格當作已實現損益。

## 必須實作

- 保存成交唯一鍵、券商委託號、帳號遮罩、商品契約、買賣別、開平、數量、成交價、成交時間、手續費、交易稅與來源。
- 以 decimal／整數最小貨幣單位及商品乘數計算；支援部分成交、多次加碼、分批平倉與反手。採用的配對法（券商已實現值、FIFO 或加權平均）必須可追溯並與對帳單定義一致。
- 每日依交易日而非單純曆日彙總；每月由每日結果彙總。分別顯示毛損益、手續費、稅費、淨損益與成交口數。
- 尚未平倉的浮動損益可另列，但不得混入客戶要求的實際成交損益。
- 支援 UI 篩選與 CSV/Excel-friendly UTF-8 BOM 匯出；匯出包含產生時間、時區、查詢期間及資料完整性警示。
- 若成交回補不完整、費用未知或與券商查詢不符，數字標記 provisional，不得靜默顯示為最終值。

## 驗收

用已知答案 fixture 測試多／空、1／2 口、部分成交、跨午夜、跨月、費稅、反手與重複回報。以數份匿名券商對帳範例做 reconciliation，記錄容許差異與原因。報表能下鑽到構成每筆損益的成交。
