# Feature 12 — Windows Desktop UI

> **平台硬性限制：整個系統只能使用 x32；不得使用 x86 或 x64。原因是行情 API 僅提供 x32 版本。所有開發、相依套件、執行環境、測試、建置與部署均須遵守此限制。**

> 強制使用 Python 開發；Windows UI 應選擇適合長時間運行且可封裝元大 API thread/COM 限制的 Python GUI framework。

## 任務

建立繁體中文 Windows 操作介面，讓使用者能安全啟動、暫停、停止、監看與處理異常。UI 只呼叫 application commands，不直接操作元大 API，也不能自行改寫交易狀態。

## 畫面需求

- 頂部永久顯示環境（模擬／正式）、連線健康、策略狀態、商品、契約月份、元大實際持倉與最後同步時間。
- 控制：啟動、暫停、停止、重新查詢、確認同步、緊急平倉。依狀態禁用不合法按鈕；高風險操作要顯示具體影響並確認。
- 行情區：最新價、bid/ask（若 API 提供）、時間、資料新鮮度、forming 60m K 與最近 closed K。
- 策略區：紅／黑／十字判斷、連續計數、最後處理 K、允許建倉時間、目前／最近訊號、阻擋原因與加碼設定。
- 委託成交區：本地 ID、券商單號、方向、開平、口數、累計成交、狀態、時間及錯誤；Unknown/Rejected/Partial 明顯標示。
- 損益區：每日、每月實際成交毛／淨損益與明細查詢。
- 訊息區：錯誤、斷線、持倉不一致、人工處置指引與可搜尋交易紀錄。

## 行為與安全

UI thread 不得被 API callback 或查詢阻塞。視窗關閉、Windows shutdown、最小化、睡眠喚醒需走安全生命週期；有持倉／活動或未知委託時不得無提示退出。策略暫停與停止的語意要在介面中解釋，且不以顏色作唯一提示。

## 驗收

用 view-model 測試所有按鈕 enablement 與狀態顯示；做 100%/125%/150% DPI、常見解析度與長時間 log 更新測試。建立操作驗收腳本涵蓋登入、啟動、訊號、成交、暫停、外部持倉差異、人工同步、緊急平倉與結束程式。
